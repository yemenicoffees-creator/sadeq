### 3. المعمارية التقنية وخطة التنفيذ

```
┌─────────────────────────────────────────────────────────┐
│               initialData.ts (البيانات الأساسية)         │
│  - 8 فروع بأرقامها وساعات عملها الصباحية والمسائية        │
└───────────────────────────┬─────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────┐
│            AppContext.tsx (مزامنة التخزين)              │
│  - ترقية مفتاح التخزين yctc_branches_v2 لتطبيق الفروع   │
│  - دعم الهاتف والواتساب المباشر لكل فرع                 │
└───────────────────────────┬─────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────┐
│        BranchesSection.tsx & BranchesView.tsx           │
│  - عرض البطاقات مع زر الاتصال وزر الواتساب وساعات العمل │
└─────────────────────────────────────────────────────────┘
```

### 4. خطوات التنفيذ بعد الاعتماد
1. تحديث `src/data/initialData.ts` بإضافة الفروع الثمانية بالأرقام الجديدة وساعات العمل (8-12 و 3-8).
2. تحديث `src/context/AppContext.tsx` لرفع إصدار مفتاح التخزين (`yctc_branches_v2`) لضمان ظهور البيانات الجديدة فورياً.
3. تحديث `src/components/BranchesSection.tsx` و `src/components/Footer.tsx` و `src/views/BranchesView.tsx` لإظهار زر اتصال مباشر وزر واتساب مخصص لكل فرع مع ساعات العمل الجديدة.
4. التحقق من بناء المشروع عبر `compile_applet` واختبار الواجهة عبر المتصفح.
